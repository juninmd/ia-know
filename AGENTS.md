# IA Know

AI/LLM knowledge base for developers.

## Tech Stack

- **Framework:** VitePress 1.x
- **Language:** Markdown, TypeScript
- **Formatting:** Prettier (from root config)

## Commands

```bash
npm run docs:dev       # Start dev server
npm run docs:build     # Build static site
npm run docs:preview   # Preview production build
```

## Conventions

- Documentation in `docs/` directory
- VitePress config for sidebar/nav
- Portuguese content for Brazilian dev community
- MDX-compatible markdown
